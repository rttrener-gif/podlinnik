# ПОДЛИННИК — дело № 24-0417

Браузерная детективная игра в жанре true crime. Полностью оригинальное вымышленное дело: ~45 материалов, 9 допрашиваемых,
22 процессуальных запроса, доска расследования, хронология, версии и финальное обвинение с пошаговой проверкой.

## Как играть

### Вариант 1. Одним файлом (проще всего)

Откройте файл `dist/index.html` двойным щелчком в Chrome / Safari / Firefox. Сервер и интернет не нужны.

> Если `dist/` нет — выполните один раз `npm install && npm run build`.

### Вариант 2. Через локальный сервер

```bash
npm install
npm run dev
```

Откройте адрес из терминала (по умолчанию http://localhost:5173). С телефона в той же сети — адрес «Network» из вывода.

## Что умеет игра

- **Материалы** — протоколы, показания, переписки (в виде скриншотов), расшифровки аудио, таблицы звонков, чеки, «фотографии»,
  схема усадьбы. Любую фразу можно отметить звёздочкой как важный факт.
- **Люди** — досье и интерактивные допросы: выбираете вопросы и предъявляете улики, ответы зависят от того, что вы уже знаете.
- **Запросы** — экспертизы, детализации, выгрузки. Каждый запрос требует основания и открывает новые материалы.
- **Доска** — перетаскиваемые карточки и подписанные «нити» между уликами.
- **Хронология**, **Версии и противоречия**, **Заметки**, **Журнал** — ваш рабочий инструментарий.
- **Обвинение** — кто, как, когда, мотив, доказательства, ложные показания. Если версия неверна, игра объяснит, что именно не
  подтверждается, и позволит продолжить. Решение можно показать вручную («Я сдаюсь»).

Прогресс хранится в `localStorage` браузера. Начать дело заново можно на обложке (с подтверждением).

## Технически

React 18 + TypeScript + Vite, без серверов, внешних API и ключей. Шрифты подключены локально (`@fontsource`).
Сюжетные данные — в `src/content/`; проверка обвинения и разгадка загружаются лениво (`src/content/solution.ts`).

Проверка целостности сюжетного графа (достижимость всех материалов, ссылки, оценка обвинения):

```bash
npx tsx tools/check.ts   # дело 1
npx tsx tools/check2.ts  # дело 2
npx tsx tools/check3.ts  # дело 3 (в т.ч. проверка, что каждый факт финала обнаружим)
```

Все имена, организации и события вымышлены.
